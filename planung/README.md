# Kursplanung

Der Kurs beginnt neu. Die bisherigen fünf Kurzlektionen und der alte
19-Lektionen-Plan sind keine Grundlage für die neue Reihe.

- [Hauptplan](hauptplan.md): die vollständige Grammatiklandkarte mit den
  ursprünglichen Nummern 1–90 und den vom Lernenden festgelegten Arbeitsregeln.
- [Block 1 im Detail](bloecke/block-01.md): vier Klassen, aufgeteilt in neun
  zusammenhängende Hörtexte. Die ersten drei Texte sind ausgearbeitet.

Ein **Block** ist ein nummerierter Themenbereich des Hauptplans. Eine
**Klasse** ist eine didaktische Untereinheit. Ein **Text** ist eine separat
abspielbare deutsche Lektion mit ihrer portugiesischen Parallelfassung.
Eine Klasse kann mehrere Texte brauchen. Die Nummer eines Blocks ist keine
zwingende Unterrichtsposition: Voraussetzungen bestimmen die Reihenfolge.

Weitere Blockpläne werden erst bei ihrer Ausarbeitung hier ergänzt.
